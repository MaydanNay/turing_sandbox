# Портреты для приватного чата (кулуары)

Кладите сюда **полноразмерные** изображения персонажей для экрана приватного чата.

## Именование

`{id}_chat.png` — id персонажа, как в `characters/chibi/`:

```
cole_chat.png
martha_chat.png
chester_chat.png
roxy_chat.png
```

Сейчас загружены все 8 персонажей: **vance**, **cole**, **martha**, **penny**, **gwen**, **logan**, **chester**, **roxy**.

Остальные id пока используют chibi-спрайт, затем `chibi/default.png`.

## Рекомендации

- PNG или WebP, прозрачный фон
- Вертикальный или полный рост, персонаж «стоит» — изображение прижато к низу экрана
- Ширина ~800–1200 px, пропорции сохраняются (`object-contain`)

После добавления нового файла добавьте id в `CHAT_PORTRAIT_IDS` в `src/config/assets.ts`.
